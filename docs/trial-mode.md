# 零成本体验版路线

> 目标：让身边的几个人扫码就能用上真实数据，**一分钱不花，不备案、不买域名、不买服务器**。
>
> 适合：自己测试、给同学朋友玩、边用边改。不适合：给不认识的人用、需要 7×24 可用。

---

## 为什么这条路能成立

三件事凑在一起，把成本和门槛都消掉了：

| 平时必须做的 | 为什么这里可以跳过 |
|---|---|
| 买云服务器 | 后端跑在你自己电脑上，用内网穿透开个公网口子 |
| 买域名 + 备案 | **不提交审核就不需要备案**。体验版只在成员之间流通 |
| 配 HTTPS 证书 | 手机上加一次「打开调试」，微信就跳过域名和证书校验 |

代价只有一个：**你的电脑不能关机**。这一条接受了，其余全是零成本。

---

## 整体链路

```text
朋友的手机（微信打开体验版）
        │
        │  HTTPS 请求
        ▼
frp-hat.com:41561            ← SakuraFrp 公网入口（必须开「自动 HTTPS」）
        │
        │  脱掉 TLS 壳，用明文转给你本机
        ▼
你的电脑
  ├─ Spring Boot  :8080      ← 后端（仍然是明文 HTTP，不用改）
  └─ MySQL        :3306      ← 数据库
```

**为什么要 HTTPS**：国内节点禁止明文 HTTP 走隧道，否则网关直接返回 501。
所以 HTTPS 是 SakuraFrp 那边加的壳，你的后端不用动。

**理解了这张图，后面每一步的位置就清楚了**：第 1 步修好最右边，第 2 步修通中间，
第 3–4 步让最左边能连上，第 5–6 步才是给别人用。

---

## 八步，严格按顺序做

每一步都有一个「检查点」。**检查点不过，不要往下走** —— 否则出了问题你不知道是哪一环。

### 第 0 步 · 装微信开发者工具

**为什么先做这个**：它是「编译产物 → 真机」的唯一通道。没有它，后面所有步骤都做不了。

1. 打开 <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 下载「稳定版 Stable Build」的 Windows 64 位
3. 安装后打开，用**你自己的微信**扫码登录

⚠️ 登录的微信必须是小程序 `wxd3a43865e64253c9` 的管理员或开发者，
否则导入项目时会提示没有权限。

✅ **检查点 0**：能看到开发者工具主界面，左上角显示「小程序」。

---

### 第 1 步 · 让后端在本机跑起来

**为什么**：先把「代码本身对不对」验证掉。这一步不通，后面全是白费力气。
它和网络、穿透、小程序一点关系都没有，是最容易排查的一环。

```bash
cd class-assistant/backend/class_assistant_server

DB_PASSWORD=你的数据库密码 ./mvnw spring-boot:run \
  '-Dspring-boot.run.arguments=--server.port=8080'
```

两个容易踩的点：

- **必须显式传 `--server.port=8080`**。环境里有个 `SERVER__PORT` 变量会被 Spring
  的宽松绑定当成 `server.port`，导致端口变成别的值然后报「已被占用」。
- **第一次跑不要加 `-o`（离线）**。`spring-boot:run` 的运行期依赖没下载过的话离线会失败。
  编译可以离线，启动不行。

看到这行就是成功了：

```
Started ClassAssistantServerApplication in x.xxx seconds
```

验证（另开一个终端）：

```bash
curl -s http://127.0.0.1:8080/api/teacher/home/overview
```

期望返回 `{"code":1002,"message":"未登录"...}`。
**这个「报错」就是成功** —— 说明服务活着、拦截器生效了。

✅ **检查点 1**：curl 返回 `code:1002`。

---

### 第 2 步 · SakuraFrp 开一条隧道

**为什么**：你的电脑在家庭宽带后面，外面的手机根本找不到它。
内网穿透就是给你电脑开一个公网门牌号。

#### 2.1 建隧道

1. 打开 SakuraFrp 启动器（`C:\Program Files\SakuraFrpLauncher`），登录账号
2. 如果提示需要**实名认证**，先去做 —— 国内节点必须实名，免费的
3. 新建隧道，按这个填：

| 字段 | 填什么 |
|---|---|
| 隧道类型 | **TCP** |
| 本地地址 | `127.0.0.1` |
| 本地端口 | `8080` |
| 备注 | 班级助手后端 |

4. 保存后启动隧道，面板上会显示一个地址，形如 `frp-hat.com:41561`

⚠️ **这条隧道不要删**。免费隧道只要不删，地址就一直固定；
删了重建地址会变，前端就得重新构建上传。

#### 2.2 必须开「自动 HTTPS」

**这一步不能跳。** 国内节点现在禁止明文 HTTP 通过隧道（机房合规要求）。
不开的话，访问任何地址都会返回一个 `501 Not Implemented` 的 SakuraFrp 拦截页，
请求根本到不了你的后端。

操作：

1. SakuraFrp 面板 → 编辑刚才那条隧道
2. 找到 **「自动 HTTPS」**，选择 `自动`（或 `启用`）
3. 保存 → **重启隧道**（必须重启才生效）

官方文档对「应用的 HTTP API（国内节点）」的结论是**必须开**，你这正好是这类。

开启后的原理：frpc 用 TLS 接住外部请求，把壳脱掉，再用明文 HTTP 转给本机 8080。
所以**后端不用改，也不用配证书**。

> 参考：<https://doc.natfrp.com/frpc/auto-https.html>

#### 2.3 验证（关键一步）

**手机上关掉 WiFi，用流量（4G/5G）**，浏览器打开：

```
https://你拿到的地址/api/teacher/home/overview
```

注意三件事：

- **是 `https://`，不是 `http://`**
- **路径是 `home`，不是 `homr`** —— 拼错会返回 404，很容易误判成别的问题
- 末尾是 `/overview`，完整路径 `/api/teacher/home/overview`

期望看到 `{"code":1002,...}`。
**这个"报错"就是成功** —— 说明服务活着、拦截器生效了。

浏览器可能提示证书不受信任（SakuraFrp 用的是它自己的证书）。
点「继续访问」即可，小程序那边靠调试模式也会忽略证书校验。

为什么必须用流量：连着 WiFi 时手机可能走的是内网路径，
验证不到「外网真的能访问」。只有走运营商网络才算数。

✅ **检查点 2**：手机流量下能看到 `{"code":1002}`。

> 如果这一步不通，先别管小程序。按顺序查：
> ① 隧道是否「运行中」② 自动 HTTPS 是否开了并重启过 ③ 地址端口有没有抄错
> ④ 后端是否还在跑（回到第 1 步 curl 一次）⑤ 电脑防火墙是否拦了
> ⑥ SakuraFrp 免费流量是否用完

---

### 第 3 步 · 前端指向穿透地址，重新构建

**为什么**：前端现在默认连 `localhost:8080`，而手机上的 `localhost` 是手机自己。
必须把地址改成隧道地址，打进包里。

```bash
cd class-assistant/frontend/uni-app/my-mp

cp .env.production.example .env.production
```

编辑 `.env.production`，改成你的地址（**必须是 `https://`**，因为国内节点只放行 HTTPS）：

```ini
VITE_API_BASE_URL=https://frp-hat.com:41561/api
```

两个容易写错的地方：

- **`https://` 不能写成 `http://`** —— 会被网关拦成 501
- **末尾的 `/api` 不能省** —— 它和后端的接口前缀是配套的，漏了会全部 404

```bash
npm run build:mp-weixin
```

验证产物里真的写进去了：

```bash
grep -o "frp-hat[^\"]*" dist/build/mp-weixin/api/request.js
```

应该看到你的地址。**如果什么都没输出，说明环境变量没生效**，别往下走。

> `grep` 的关键词换成你自己隧道域名的一部分（`natfrp`、`frp-hat` 等）。

✅ **检查点 3**：`grep` 能打印出你的隧道地址。

---

### 第 4 步 · 在开发者工具里跑通

**为什么**：在真机之前先确认配置对。开发者工具里不用开调试模式，
排查起来比手机方便得多（有控制台）。

1. 开发者工具 → 导入项目
2. **目录选 `class-assistant/frontend/uni-app/my-mp/dist/build/mp-weixin`**
   （注意不是 `src`，也不是 `dist/dev`）
3. AppID 填 `wxd3a43865e64253c9`
4. 右上角「详情」→「本地设置」→ 勾选
   **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
5. 点「编译」

看首页：应该显示 `628班`、`47 人在读`、四宫格有数字。
点几下学生、成绩、待办，看有没有数据。

⚠️ 如果首页转圈或报「网络异常」，看控制台的请求地址对不对，
再用第 1 步的 curl 确认后端还活着。

✅ **检查点 4**：首页有真实数据，能点进学生列表。

---

### 第 5 步 · 真机预览，开调试模式

**为什么**：模拟器和真机是两回事。这一步验证「手机真的能连上」，
也是体验版能否用的最后一道关。

1. 开发者工具点「预览」
2. 手机微信扫码打开
3. **点右上角「···」→「打开调试」**
4. 小程序会重启，右下角出现一个绿色 `vConsole` 按钮

看数据是否正常显示。如果开了调试还是不通，用 vConsole 的 Network 面板看请求
—— 那里能看到真实的 URL 和错误。

✅ **检查点 5**：手机上数据正常，vConsole 没有红色报错。

---

### 第 6 步 · 上传体验版，加体验成员

**为什么**：到这一步朋友才能用。他们不用装开发者工具，扫码就行。

#### 6.1 上传

开发者工具点「上传」，版本号填 `1.0.0`，备注写「首个体验版」。

#### 6.2 设为体验版

1. 打开 <https://mp.weixin.qq.com>，用管理员微信登录
2. 左侧「管理」→「版本管理」
3. 在「开发版本」里找到刚上传的，点右侧「···」→「选为体验版」

#### 6.3 加体验成员

1. 左侧「管理」→「成员管理」
2. 「体验成员」→ 添加，输入朋友的微信号

⚠️ **个人主体小程序最多 15 个体验成员**。够用了。

#### 6.4 发给朋友

体验版页面会生成一个二维码，**有效期 7 天**，过期重新生成即可。

把二维码发给朋友，并告诉他们：

> 扫码打开后，点右上角「···」→「打开调试」。

这一步朋友也必须做，否则微信会拦掉所有请求。

✅ **检查点 6**：朋友扫码后能看到真实数据。

---

### 第 7 步 · 以后每次改代码

形成了固定循环，每次都是这四句：

```bash
# 1. 改完代码后重新构建
cd class-assistant/frontend/uni-app/my-mp
npm run build:mp-weixin
```

2. 开发者工具里点「上传」，版本号加一（`1.0.1`、`1.0.2`…）
3. 后台「版本管理」→ 新版本「选为体验版」（**会覆盖旧的**）
4. 朋友重新扫体验版二维码即可

⚠️ **上传完不「选为体验版」的话，朋友看到的还是旧版**。这一步最容易忘。

## 让电脑别休眠

这是整套方案唯一需要额外注意的地方。Windows 默认会睡眠，
一睡后端就断了，朋友打开就是「加载失败」。

控制面板 → 电源选项 → 更改计划设置 → 把「使计算机进入睡眠状态」改成**从不**。

（只在你需要让朋友用的这段时间改，不用长期这样。）

## 常见故障

| 现象 | 原因 | 怎么办 |
|---|---|---|
| **`501 Not Implemented`（SakuraFrp 拦截页）** | **国内节点禁止明文 HTTP** | **编辑隧道 → 自动 HTTPS 选「自动」→ 重启隧道 → 改用 `https://` 访问** |
| 返回 404，页面是 JSON 的 `1004` | 路径拼错（如 `home` 写成 `homr`） | 核对完整路径 `/api/teacher/home/overview` |
| 手机浏览器打不开隧道地址 | 隧道没启动 / 地址抄错 | 看 SakuraFrp 面板是否「运行中」 |
| 手机 WiFi 能开、流量打不开 | 走的是内网路径，不是真穿透 | 必须用流量验证；检查隧道是否真的建立了公网映射 |
| 浏览器提示证书不受信任 | SakuraFrp 用自己的证书 | 点「继续访问」；小程序侧靠调试模式忽略 |
| 开发者工具里转圈 | 后端没启动 | 回到第 1 步，curl 一下 |
| 提示 `url not in domain list` | 没开调试模式 | 右上角「···」→「打开调试」 |
| 提示 `request:fail` 且没别的信息 | 地址错了 / 端口不通 | 手机上用浏览器直接访问那个地址试试 |
| 朋友扫码提示「无权限」 | 不在体验成员名单里 | 后台「成员管理」加上 |
| 朋友看到的是旧界面 | 上传后没重新「选为体验版」 | 后台重新选一次 |
| 首页数据全是 0 / 未绑定班级 | 登录的不是李光老师 | 确认后端 `WX_MOCK=true`（默认就是） |
| 之前能用，突然全挂了 | 电脑休眠了 / 隧道断了 | 唤醒电脑，重启隧道 |
| SakuraFrp 提示流量不足 | 免费版有日流量限制 | 控制台看用量，或换 cloudflared 临时顶一下 |

## 什么时候该升级到付费方案

出现下面任意一条，说明该花那 200 块了：

- 你需要**关电脑**（出门、上课、睡觉时也想让别人能用）
- 想让**不认识的人**用（15 个体验成员不够）
- 想让微信里搜得到（必须提审 → 必须备案 → 必须域名）
- 隧道经常断，朋友抱怨打不开

升级路径见 [`deploy/README.md`](../deploy/README.md)，那边是完整的生产部署。

在那之前，**先把这个跑通、把功能玩明白**。功能没定下来就先去买服务器，
大概率是花钱买了个放在那里吃灰的机器。
